# GARAGE 59

Концепт одностраничного сайта автосервиса (портфолио). React + TypeScript + Vite.

## Локальный запуск

```bash
npm install
npm run dev
```

## Публикация

Сайт деплоится на **GitHub Pages** при push в ветку `main` (workflow `.github/workflows/deploy-pages.yml`).

Публичный адрес после первого успешного деплоя:

Публичный сайт: **https://projectescape463-hash.github.io/garage-59/**

Репозиторий: **https://github.com/projectescape463-hash/garage-59**

Демо-контакты и цены: `src/data/`.
